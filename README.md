# AEORank

AEORank is no longer open source.

This repository was converted to an archived public notice on March 21, 2026. Active development moved to AEO Content's private codebase and continues inside the `aeocontent-ai` monorepo.

## Current Status

- GitHub source development is private going forward.
- The original public npm package `aeorank` has been deprecated.
- The private distribution target is `@aeocontent/aeorank`.
- This repository is intentionally code-free and archived.
